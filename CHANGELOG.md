# Changelog

All notable changes to this project are documented in this file.

## [0.0.4] - 2026-10-12

- Calendar descriptions now include labelled links to the ToDo and directly linked records, separated by blank lines.
- Additional Link and Dynamic Link fields on ToDos are supported; duplicate links are omitted.

## [0.0.3] - 2026-10-08

- Added a concise German end-user guide for ERPNext and Outlook.

## [0.0.2] - 2026-10-08

- Added AI contributor instructions for mandatory version bumps and change logging.
- Expanded the setup and security documentation for the Outlook calendar feed.

## [0.0.1] - 2026-10-08

- Initial release of the ERPNext ToDo Outlook calendar feed.
